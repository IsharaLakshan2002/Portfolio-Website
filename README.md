# Ishara Lakshan — Portfolio

React + TypeScript + Vite + Tailwind CSS v4, with Motion and GSAP.

## Run locally

```bash
npm install
npm run dev
```

## Build and deploy (GitHub Pages)

```bash
npm run build
npm run deploy
```

The build uses relative asset paths, so it also works on Vercel or Netlify.
